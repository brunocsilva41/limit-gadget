# COMO USAR O LIMITGADGET

1. Execute `LimitGadget_0.1.0_x64-setup.exe` (ou `.msi`)
2. Após instalar, procure o ícone **na bandeja do Windows** (próximo ao relógio)
3. Clique no ícone → abre o painel com os limites
4. A janela pode ser fechada com o X; ela reaparece ao clicar no ícone

Se não aparecer de imediato: abra o Gerenciador de Tarefas → procure "limit-gadget".
